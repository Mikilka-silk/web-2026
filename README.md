# web-2026
Laboratory Works 3 and 4: CRUD Javascript App
Laboratory Work 3: View Page Description:
This work involves making a simple presentation part of a website - a View Page. The data used for the blocks is taken from a java/python project class or a chosen free task.   Implemented Features:Sort of your items option. Search option. Count total amount of some of the field (e.g., total price of all cars). Technical Details:The project utilizes JS Array methods, such as map(), sort(), filter(), and reduce().   Native JS is used for any DOM operations, including querySelector, findById, and insertAdjacentHTML. Responsiveness is absolutely not required for this work.   Styling is not important at all and is up to the developer.   

Laboratory Work 4: Create/Edit Pages   Description:
This part continues the development by adding two new parts to the website: Create and Edit Pages. Note that Update/Delete operations are not required for this work. Implemented Features:The forms are validated using HTML attributes, and inputs are configured for the specific data format. If incorrect data is entered in the inputs, JavaScript is used to inform the user using modal windows or a plain alert() function. Technical Details:Similar to the previous work, responsiveness is absolutely not required. Styling is not important at all and is left to the developer's preference.
